# 接口处理源 打包说明

本包按「存活源 / 失效源」两级分目录，每级之下再按「文件类型 → 内容分类」细分。

## 核验方式
- 对去重后源文件提取其自身 API/主域名（剔除 B站/腾讯/夸克/Telegram/图床等第三方引用）
- 逐目标发起 HTTP 请求：并发 24、超时 8s、浏览器 UA、允许重定向、单次不重试
- 存活判定：HTTP 响应（含 401/403/404 均视为服务在线）
- 失效/异常：DNS解析失败、连接被拒绝/失败/超时、读取超时、5xx、SSL错误 等

## 统计
- 可检测源总数：1200
- 存活源：853
- 失效/异常源：347
