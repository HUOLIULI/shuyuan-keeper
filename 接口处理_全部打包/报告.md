# 接口处理源（含 GitHub 源）全部汇总 · 分类 · 核验报告

## 范围
合并三部分源并去重（按 API）：
- 接口处理_整理结果：1200 个可探测源
- GitHub `docs/valid_videosite.json`：76 个 URL 影视源
- GitHub `docs/valid_tvbox.json`：140 个 http API 源

去重后 **唯一可探测源 1167 个**（音乐源因托管在 CDN 脚本上，不纳入源站核验）。

## 核验方式
- 对每个源提取 API/主域名，逐目标 HTTP 探测（并发24/超时8s/浏览器UA/允许重定向/单次不重试）
- 存活：HTTP 响应（含 401/403/404）；失效：DNS解析失败/连接失败/拒绝/超时/5xx/读取超时 等
