# PeekPro 本地覆盖包

## 这是什么
基于 drpy-node 的 PeekPro 1.5.8 本地源覆盖包，包含 112 个经过验证的 drpyS 源。

## 安装方法
1. 先安装 PeekPro 1.5.8 并部署基础 drpy-node 环境
2. 把本包解压到 `/storage/emulated/0/peekpro/`（覆盖 php-scripts）
3. 重启 PeekPro，接口配置选择 `T4接口`，地址填：
   ```
   http://127.0.0.1:5757
   ```
4. 或直接导入本包内的 `index.json` 作为 TVbox 订阅

## 目录结构
```
peekpro/
└── php-scripts/
    └── (drpy-node 运行时)
    └── spider/
        ├── js/      ← 111个drpyS源脚本（本包提供）
        └── jx/      ← 解析接口
    └── index.json   ← 站点配置（本包提供）
```

## 注意
- 本包不含 drpy-node 运行时（太大），需配合官方基础包使用
- 安卓10以上可用，iOS不支持本地包
- 源的存活状态每日自动检测更新
